## 首跑错误与纠正

1. 系统 `python3` 指向失效的 Windows 应用别名，退出 9009。第一轮旧版仅 1732 通过、20 失败、152 跳过，不纳入正式结论。保留报告和退出码。
2. 在临时目录提供真实解释器副本及配套运行库，仅为验证进程设置命令搜索路径及 `PYTHONHOME`。已实际验证 `python`、`python3` 的直接子进程调用和命令行调用都能加载相同解释器及标准库。未更改系统全局配置、仓库测试或产品实现。
3. 修好解释器后，首个旧版导出仍出现 18 失败。其中一项是 `git archive` 受 Windows 换行转换影响：子模块工作流变为 CRLF，主仓库来源保持 LF；原始两个版本库对象实际相同。
4. 使用 `git -c core.autocrlf=false -c core.eol=lf archive` 重新导出旧版主仓库和其固定子模块，验证工作流逐字节一致，再完整重跑命令行测试，得到正式的 1852 通过、17 失败、35 跳过。没有更改测试断言或屏蔽失败；前两轮报告原样保留。
