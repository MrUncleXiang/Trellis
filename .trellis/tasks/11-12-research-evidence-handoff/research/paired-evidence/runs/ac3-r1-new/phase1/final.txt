结论：**`vendor/prompt-kit` 这个固定本地副本不支持原生批量渲染，但可以通过逐项调用返回独立结果。**

依据一致：

- 本地版本为 `@fixture/prompt-kit` 2.0.0，只导出 `renderOne`，源码仅做字符串转换。
- 文档明确说明没有原生批量接口。
- 实测传入 `["a","b"]`，得到单个字符串 `"a,b"`。这相当于把几张单据合成一行字，不能保留每张单据的边界。

建议方案是：**调用方按输入位置逐项调用 `renderOne`，收集等长、同序的结果数组。** 不改第三方副本，也无需引入并发。

例如输入 `["a", "", "a"]`，建议返回：

```json
[
  { "index": 0, "ok": true, "value": "a" },
  { "index": 1, "ok": true, "value": "" },
  { "index": 2, "ok": true, "value": "a" }
]
```

其中 `index` 表示输入位置，重复值和空串都保留。建议单项出错时，该位置返回失败结果并继续处理后续项；**这是待审阅设计，尚未实现或验证异常路径**。
