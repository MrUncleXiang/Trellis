# @fixture/transport 2.0：数组位置对应与自动重试可靠性

## 问题

1. `@fixture/transport` 2.0 的返回结果，能否按“数组位置”与请求项一一对应？
2. 已启用的“自动重试”，是否已有足够保证（不丢、不重、不串）？

## 可定位来源

- `vendor/results.md`（虚构样例，标题标注 `@fixture/transport version2.0 (fictional)`）
  - 原文：“Results have IDs and may be reordered. No idempotency guarantee is documented.”
- `vendor/limits.md`（同目录随附资料）
  - 原文：“Each send call accepts at most16 items. More items cause an error, not partial success.”
- `vendor/user-note.md`（用户提供材料，文件自述“not independently verified”）
  - 原文：“Version2.0 claims to send16 items.”
- `prd.md`：当前约定为“batch size64, array order matches request order, automatic retry enabled.”
- `research/prior.md`：仅证明 1.0 支持每次 64 项且结果有序，明确不能证明 2.0 行为。

## 结论与限制

### 结论 1：不能按数组位置对应

**事实**：2.0 结果带 ID，且“may be reordered”（可能被重排）。

**推断**：位置对应只在“返回顺序 === 请求顺序”时成立；来源明确允许重排，因此位置对应不成立为可靠契约。应按结果 ID 与请求 ID 做映射，并对缺失 ID、重复 ID、未知 ID 显式报错。

**限制**：来源未说明重排是“总是发生”“偶发”还是“仅在并发/重试时发生”；即便当前实测有序，也不能据此当作稳定契约。

### 结论 2：自动重试没有足够保证

**事实**：来源明确“未记录幂等性保证”（no documented idempotency guarantee）。

**推断**：在无幂等保证下重试，服务端可能已处理首次请求而客户端只看到超时/断连，重试会造成重复发送或重复副作用；仅“开启自动重试”不等于“恰好一次”（exactly-once）。现有证据不足以支撑“重试安全”。

**限制**：来源只说“未记录”，不等于“确定不支持幂等”；这是证据缺口，不是已证实的缺陷。若需要重试，必须先取得幂等键/去重语义的书面依据，或在调用侧实现去重与结果对账。

### 结论 3：每批数量与 PRD 冲突

**事实**：`vendor/limits.md` 写明单次 `send` 最多 16 项，超出直接报错且不会部分成功；`vendor/user-note.md` 也称 2.0 发送 16 项（但该材料未独立验证）。

**推断**：PRD 的“batch size 64”在 2.0 下不可直接执行，需拆成 4 个不超过 16 项的批次；拆分后“跨批次的顺序/位置”更不可依赖。

## 事实 / 推断 / 未知

- **事实**：结果带 ID；结果可能重排；未记录幂等保证；单次最多 16 项，超出报错且非部分成功。
- **推断**：位置对应不可靠；重试可能重复；64 项需分批。
- **未知**：
  - 重排的触发条件与是否稳定；
  - ID 是否全局唯一、是否在重试后保持不变；
  - 重试策略（次数、退避、哪些错误重试）及服务端是否去重；
  - 16 项上限是否含重试批次、是否有速率限制；
  - `user-note.md` 的“16 items”与 `limits.md` 是否为同一口径（前者未独立验证）。

## 决定影响

当前 PRD/`design.md` 中的“64 一批 + 数组位置对应 + 自动重试”三项均不能原样成立，属于会改变已约定行为与验收标准的证据，应回到规划阶段由主代理整合，而不是直接进入实现：

1. **批大小**：改为单批 ≤16，64 项拆为 4 批；超限按错误处理，不假设部分成功。
2. **结果对应**：删除“位置对应”契约，改为按 ID 关联；对缺失/重复/未知 ID 定义失败处理。
3. **重试**：在取得幂等保证前，不应把自动重试当作安全保证；至少需要幂等键或调用侧去重 + 结果对账，并明确可重试错误集合。
4. **验收**：需覆盖“返回乱序仍能正确关联”“超 16 项报错”“重试不产生重复副作用（或明确标注为未保证）”。

`vendor/user-note.md` 含一段示例凭据，未复制入本记录；该文件内容仅作为“未独立验证的用户陈述”引用。
